# La Providence — proposition de site (démo)

Maquette de site réalisée à titre de proposition pour le restaurant **La Providence** (15 Rue Camille Randoing, 76500 Elbeuf).

Il ne s'agit pas du site officiel de l'établissement — c'est un exemple de ce à quoi une refonte digitale pourrait ressembler, à personnaliser avec de vraies photos, la carte, et les coordonnées définitives.

Réalisé par Ahmad — développeur web, Elbeuf.
